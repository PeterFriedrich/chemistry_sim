## 3. Technical Learnings
- **The pdf.js text layer is a reliable second reading. pypdf is not.** In the old render page, `getTextContent()` gives each string with its x, y and font size.
  - On pp. 2–3 the fonts are: atomic number 13.7, symbol 19.6, mass 9.8, charges and EN 7.8, names 9.8 (long names 8.8), polyatomic sub/superscripts 4.9.
  - Assign items to a cell by the atomic number's position (x from −6 to +58, y from −60 to +3). Items 15 or more below the atomic number are the EN; the rest are charges.
- **The text layer can be wrong where the image looks right:** it has "CIO" for ClO and an en dash in H's "1+,1–". Use both readings, and settle any disagreement with the chemistry.
- **Seed errors to test a comparison script.** Mine missed a seeded Pb mass, because Pb's expected value was the literal `'207.2*'`.
- **Tooling:** the render tooling was copied from the S06 scratchpad (`a7b32c9f…/scratchpad/render`, which has `index.html` and the pdf.js files, plus `py/` with Pillow and pypdf).
  - ⚠️ An old `python3.12 -m http.server 8765` from S06 was **still running**, serving S06's `render/` directory. New HTML files have to go there, or you have to kill it: `pkill -f "http.server 8765"`.
  - Playwright CJS scripts need `NODE_PATH=/tmp/pw/node_modules`.
- **The booklet PDF at the DATA_SHEET URL is unchanged** (md5 `f2d3fb561b419f63b34f0d1039e4a6ae`, 556 738 bytes, re-fetched 2026-09-28).
