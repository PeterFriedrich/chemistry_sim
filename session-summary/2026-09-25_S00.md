## 3. Technical Learnings
- **Workflow (owner, this session):** do NOT commit to `main`. Put each unit on its own branch, open a PR, and the owner merges. The owner merges fast: both PRs merged within minutes, and PR #2 had merged before this handoff. Always `gh pr view N --json state` before pushing to an existing branch. This is also saved in memory.
- **`npm run verify` works on the Oracle server.** `~/.cache/ms-playwright` holds chromium-headless-shell rev 1228, which matches **playwright@1.61** only (1.62 wants 1234, 1.63 wants 1243). Install it outside the repo, e.g. `npm i --prefix <scratch>/pw playwright@1.61`, then run `NODE_PATH=<scratch>/pw/node_modules VERIFY_WIDTHS=390,1280 npm run verify` (add `VERIFY_THEME=dark` for dark mode). This corrects the S00 claim that verify was VM-only.
- **`npm run check` fails on this server** because its `python3` is 3.6. Run the pieces instead: `node --test && python3.12 scripts/check_doc_citations.py && python3.12 scripts/check_decisions_log.py`.
- **Booklet extraction:** `curl` the PDF (URL in DATA_SHEET.md), `pip install --target <dir> pypdf`, then `extract_text()`. The PDF's page index is the printed page number + 2.
  - The Ka table (printed pp. 8–9) is at pdf pages 10–11; indicators (printed p. 10) at pdf page 12; polyatomic ions and the periodic table at pdf pages 2–3.
  - Charges often split onto the next line, and rows can have stray spaces ("47 .87").
- **Booklet vs textbook values:** methane combustion from the booklet is **−890.5 kJ**, not the textbook −890.3. Readouts must use the booklet.
- **Species notation:** chem modules write `Cu^2+(aq)` and `H2O(l)`, and `lib/format.js species()` renders them. The production formula parser is `molarMass()` in `chem/electrolysis.js`; `tests/atoms.js` is a separate, test-only parser (kept independent on purpose).
- Screenshot scripts for non-default states were ad hoc (scratchpad), not committed. `tools/verify-sims.js` only shoots defaults.
- **Sig-fig gap:** `fmt(1800, 3)` prints "1800", not "1.80 × 10³". That is existing `fmt` behaviour, left alone.
