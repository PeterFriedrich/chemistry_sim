- **Workflow (owner, this session):** do NOT commit to `main`. Put each unit on its own branch, open a PR, and the owner merges. The owner merges fast: both PRs merged within minutes, and PR #2 had merged before this handoff. Always `gh pr view N --json state` before pushing to an existing branch. This is also saved in memory.

  - Charges often split onto the next line, and rows can have stray spaces ("47 .87").
- **Booklet vs textbook values:** methane combustion from the booklet is **−890.5 kJ**, not the textbook −890.3. Readouts must use the booklet.
- **Species notation:** chem modules write `Cu^2+(aq)` and `H2O(l)`, and `lib/format.js species()` renders them. The production formula parser is `molarMass()` in `chem/electrolysis.js`; `tests/atoms.js` is a separate, test-only parser (kept independent on purpose).

- **Sig-fig gap:** `fmt(1800, 3)` prints "1800", not "1.80 × 10³". That is existing `fmt` behaviour, left alone.

## 3. Technical Learnings
- **Rendering booklet pages for a visual check:** the Read tool can't render PDFs here (no `pdftoppm`). Instead:
  - `python3.12 -m pip install --target <scratch>/pd pypdfium2 pillow`
  - then `pdfium.PdfDocument(pdf)[i].render(scale=1.6).to_pil().save(...)` and Read the PNG
  - Correction to S01: the pdf page index is the **printed page + 1** (0-based): Ka pp. 8–9 → indices 9–10, indicators p. 10 → 11, ion colours p. 11 → 12.
- **Floating-point rounding ties:** a hand value that ends exactly on 5 (e.g. 11.25) can round the wrong way through `toPrecision`, because the float is 11.2499…. Choose preset numbers that avoid ties, as the contact preset does with SO₃ 0.500 → Kc 7.81.
- **`fmt()` gap (now a TODO):** `fmt(1000, 3)` prints "1000", which hides sig figs. It's deliberate in `lib/format.js`, and changing it alters every sim's readouts, so propose first. The chromate preset ([CrO₄²⁻] = 0.150, Kc = 444) was picked to avoid it.
- **Sliders snap to their `step`** when set in code. For continuous animation (titrant flow), keep a separate float in the sim and write it to the slider for display.
- **`createClock` frame callback** gets `(clock, dSim)`, where `dSim` is the simulated dt. A sim with nothing to animate still needs the clock for redraws, and can hide `ui.transport`.
- **Screenshots of non-default states:** ad hoc Playwright scripts (`shots*.mjs`) using `tools/serve.js createServer()`. They live in scratch, uncommitted. Select controls by label (`page.getByLabel('Equilibrium')`), not by `locator('select').first()`, which grabs the speed selector.
- The remaining parts of `tests/atoms.js` are handy for data checks: `count` compares atom counts and `charge` compares charges, e.g. acid and conjugate base differ by one H⁺.
