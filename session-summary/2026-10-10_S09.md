## 3. Technical Learnings
- **Booklet PDFs.** The current booklet is cached at `/tmp/claude-1000/-home-opc-chemistry-sim/a7b32c9f-…/scratchpad/render/booklet.pdf` (md5 `f2d3fb56…`). The old `python3.12 -m http.server 8765` (pid 2818062) is **still serving that `render/` dir**.
  - Render a page with `index.html#<pdfPage>`, then screenshot `#c` with Playwright (`NODE_PATH=/tmp/pw/node_modules`).
  - There is no `gs` or `pdftoppm` on the box, so the Read tool cannot open PDFs; use pypdf from `…/3371fead-…/scratchpad/py` with `PYTHONPATH`.
- **The 2003 booklet** also prints melting/boiling points and ΔH fusion/vaporization (its pp. 4–5) that the current booklet lacks. They are not transcribed; see the DATA_SHEET §2 note.
- **`npm run verify` (all pages) takes more than 2 minutes per width/theme pass.** Run it with `timeout` or in the background. Don't write `until` wait loops on its output (one hung this session).
- **Commit messages: use repeated `-m` args.** `$'\n\n'` inside a double-quoted `-m` string is literal.
- **Reusable chem helpers added:**
  - `reading(str)`, `kelvin(r, unit)`, `answerSig`, `molarMassSig` and `celsius(K, sig)` in `chem/gases.js`; `dissociation` imports them.
  - `solubility(cation, anion)` in `chem/dissociation.js`.
- `naming.convert()` returns `parts` with `{label, charge, count, water?}`. It reads `HCl` without `(aq)` as molecular, so `dissociation` retries with `(aq)` to detect acids.
- Option `value`s in `lib/controls.js` `choice()` are indices in the DOM. In Playwright, use `selectOption({ index })`.
