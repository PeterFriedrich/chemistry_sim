## 3. Technical Learnings
- **`scripts/check_decisions_log.py` matches test IDs with `test_[a-z0-9_]+` — lowercase only.** A test named `…_dfH_…` was not seen and the row "named no test". Keep test IDs all lowercase.
- **Chaining with `;` let a commit go through after the guard failed** (PR #25, fixed in a follow-up commit). Chain guard → commit with `&&`.
- **`npm run check` runs the guards on the server's `python3` (3.6) and fails with `'type' object is not subscriptable`.** Run `node --test` and the two guards with `python3.12` directly.
- **Killing the dev server:** `pkill -f tools/serve.js` matches its own bash command line and exits 144. Use `kill $(pgrep -f "^node tools/serve.js")`.
- **Playwright selectors on these pages:**
  - `choice()` has a `<label for>`, so `getByLabel('Question type')` works; add `{ exact: true }` where labels overlap ("Fuel" vs "Mass of fuel burned", "Catalyst" vs "Ea … with the catalyst").
  - Slider number boxes are labelled `"<label> value"`: `fill()` then `dispatchEvent('change')`.
  - A hidden duplicate label ("Solve for" in the phase mode) needs `locator('select:visible')`.
  - Canvas-only screenshots: `page.locator('canvas').first().screenshot(...)` — far cheaper than full page.
- **Readout blocks can be hidden per row** via `dl.children[2i]`/`[2i+1]` (dt/dd pairs) — used in `sims/activation.js`.
- **`clock` frame runs every animation frame even when paused**, so plain `el('button')` click handlers that set a flag redraw without extra wiring (stability "Check my order").
- **A new sim needs:** `site/js/sims/<id>.js` (mount/equations/prompts, ≥3 prompts), a `catalog.js` entry — `tests/catalog.test.js` enforces both.
- **Booklet vs textbook values:** −2043.9 kJ/mol for propane is the booklet ΔfH° value with H₂O(g); textbooks' methane questions may use H₂O(l) (−890.5). The sims default to H₂O(g) with a toggle.
- Still true: `NODE_PATH=/tmp/pw/node_modules` for `npm run verify`; ad hoc Playwright scripts import `/tmp/pw/node_modules/playwright/index.mjs` and run from the scratchpad.
