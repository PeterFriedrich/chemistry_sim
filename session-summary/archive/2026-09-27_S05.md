## 3. Technical Learnings
- **Oxidation-number rules as a priority list** (`PRIORITY` in `chem/balancing.js`: F, Group 1, Group 2, H, O, Cl/Br/I). They are applied only while more than one element is left; the sum sets the last one.
  - This gives NaH (H −1), H₂O₂ (O −1), OF₂ (O +2) and organic C averages for free.
  - It does **not** give LiAlH₄/NaBH₄, so there is an explicit `HYDRIDE_PARTNERS` rule. Don't claim "no special cases" again.
- **Typed charge notation is ambiguous.** `NO3-` is nitrate, but `SO42-` could be SO₄²⁻ or SO₄₂⁻. The parser refuses the case of two or more digits straight into a sign in a multi-element formula. One element followed by digits (`Fe3+`, `S2-`) is read as a monatomic ion.
- **Fractional oxidation numbers:** compute electrons from whole-number totals (`Math.round(on × atoms)`), never from the float per-atom difference; `onFraction()` gives { num, den }.
- **`lib/clock.js`:** a sim's `frame()` that throws used to kill the rAF loop and freeze every control (the controls are toggled from inside `frame`). The rAF is now scheduled first.
- **Test IDs must be lowercase** (`check_decisions_log.py` regex).
- **Amending a DECISIONS row:** mark the old row in place ("PARTLY AMENDED <date> — …"), and the new row says "amends the same-day … row".
- **`git stash pop` onto a branch whose file changed** conflicts badly. Re-apply by extracting blocks from `git show stash@{0}:<path>` instead.
- **`choice()` has no element handle.** To hide one choice row: `qbox.querySelectorAll('.ctl-choice')[i]`. For a text input, use `el('input', { type: 'text' })` in a `.ctl.ctl-choice` row; its CSS is shared with `select`.
- **Playwright:**
  - wait about 300 ms after `selectOption` before checking visibility, because the frame loop toggles `display`;
  - `getByLabel('Half-reaction', { exact: true })` is needed because of "Half-reaction 1/2";
  - labels with subscripts: select by `index`.
- Still true: `npm run check` fails on `python3` 3.6. Run `node --test` and the guards with `python3.12`. Use `NODE_PATH=/tmp/pw/node_modules` for verify. Stop the server with `kill $(pgrep -f "^node tools/serve.js")`.
