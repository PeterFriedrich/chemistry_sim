## 3. Technical Learnings
- **Read booklet tables from the rendered image, not just the text extraction.** pypdf garbles cells: it lost Pb, Bi, Pt, Li, Ac and Rf, and the anion digits don't exist at all. Render with pdf.js in headless Chromium, then crop with Pillow. The pdf.js page lives in `scratchpad/render/index.html` and is served by `python3.12 -m http.server 8765`; Pillow and pypdf are installed with `pip install --target scratchpad/py`. Scratchpad paths don't survive sessions: the booklet PDF lives in older scratchpads, or fetch it again from the DATA_SHEET URL. Always cross-check the text parse against the image and list the differences.
- **Booklet facts found this session:**
  - It prints **no ion charges for the nonmetals** ("—" for N, O, F, P, S, Cl, …) and none for B, C, Si or the noble gases. Only H has 1−.
  - La and Ac are in group 3.
  - Electronegativity is "—" for the noble gases except Xe (2.6), and for Pm, Eu, Tb, Yb and Am–Lr.
  - The polyatomic table is on PDF p. 2; hypochlorite is printed "OCl⁻ or ClO⁻".
- **Guard tests tie `elements-data.js` to the DATA_SHEET table columns** (regexes in `tests/periodic.test.js`). Adding a column to the §1.8 table means updating both regexes (ions and en).
- **Module graph:** `bonding` imports `naming.parseFormula` and `naming.isMetal`, and `periodic.lewis` for bonding capacity; `forces` imports `bonding.analyse`. `isMetal` = has a positive booklet ion charge and is not H, which makes metalloids without charges (B, Si, As) nonmetals.
- **Bonding capacity = `lewis(Z).single`.** Each outer atom's bond order equals its capacity, which is why CO and SO₂ are refused. Use exact tetrahedral vectors (Math.sqrt): rounded ones made CH₄ come out "polar".
- **The sims' text inputs** follow the balancing pattern: an `el('input')` inside a `.ctl.ctl-choice` row, plus a `choice()` of examples that sets `input.value`. Recompute in `draw()` only when the value changes.
- **Display formatting of chem strings** (subscripting letter+digits, `^2-` → superscript, skipping the hydrate coefficient after "·") lives locally in `sims/naming.js` (`chem()`) and in a trimmed form in `sims/bonding.js` / `sims/forces.js` (`sub()`). With a third near-copy, lifting it into `lib/format.js` is justified if touched again. That's a shared-helper change, so propose it first.
- **Canvas hit-testing:** `periodic` maps `pointerdown` to a cell using `layout()`, the same function the drawing uses.
- The S05 environment notes still hold: `npm run check` fails on python 3.6, so run `node --test` and the guards with `python3.12`. Use `NODE_PATH=/tmp/pw/node_modules` for verify.
