## 3. Technical Learnings
- **Playwright in ESM ignores `NODE_PATH`.** Import by absolute path: `import { chromium } from '/tmp/pw/node_modules/playwright/index.mjs'`. `npm run verify` itself still works with `NODE_PATH=/tmp/pw/node_modules`.
- **Screenshot scripts write relative to cwd.** Twice this session a script run from the repo dropped PNGs into the repo root; they were removed before committing. Run ad hoc scripts with `cd <scratchpad> && node x.mjs`, and check `git status` before `git add`.
- **The readouts audit method, reusable:**
  - scratch Node probes call the `chem/` functions over slider grids
  - a Playwright dump reads `dl.readouts dt/dd` text off the live page, which catches wiring bugs the probes miss
  - a spot check can mislead: the first calorimetry repro used the swapped mass pair and showed a clean 0.00
- **`lib/controls.js` quirks:**
  - `choice()` option values are indices. Select by visible label in Playwright: `selectOption({ label })`.
  - Readout values are set with `textContent`, so HTML such as `<sub>` or `&gt;` in `out.set()` prints literally. Use Unicode (Kₐ, >).
  - To show or hide a slider row, grab `section.lastElementChild` right after creating the slider. To show or hide a readouts block, grab `ui.readouts.lastElementChild` right after `readouts()`.
- **Slider `step` quantises given values** (1.37 → 1.4). Pick steps from the precision the questions print.
- **The booklet PDF can be text-searched:**
  - `curl` the URL in DATA_SHEET.md
  - `pip install --target <scratch>/pp pypdf`
  - run it with `logging.disable` to silence the fontTools warnings
- **Textbook values differ from the booklet** (SO₂ → SO₃: −96.4 vs −98.9 kJ). Question modes that take a "given" value must not recompute it from the booklet.
- **Denied-then-ran:** a Bash call the owner rejected had already executed (it created a branch and made an edit). Check `git status` and `git branch` after a rejection.
- Canvas glyph `⋮` renders as tofu (a missing-character box) in the page font; `· · ·` works.
- Still true: the server's `python3` is 3.6, so run the guards with `python3.12`. Playwright 1.61 matches the cached Chromium.
